Open this bundle over localhost

Browsers block the preview's JavaScript module and animation file when this page is opened directly from file://.

  • On Windows, double-click start-preview.bat in this folder (it uses Python 3 if installed, then falls back to built-in PowerShell).
  • On macOS or Linux, run python3 serve.py from this folder.

If this bundle uses the Rive runtime from CDN, it also needs an internet connection.
